# mediloon-default

The default brand for the Mediloon internal tool. Overrides nothing — it *is*
the baseline: primitives come straight from `tokens/primitives.json`, logo/favicon
are the stock Mediloon mark.

Exists so a future rebrand (or a sub-team wanting its own look, per §6.5/§6.7 of
the build spec) has a second folder to diff against instead of guessing which
brand is "the real one."
